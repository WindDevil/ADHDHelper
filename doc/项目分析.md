# ADHDHelper 项目分析

> 分析日期：2026-05-12

## 项目定位

**ADHDHelper** 是一款桌面全屏提醒应用，面向 ADHD（注意力缺陷多动障碍）患者或容易分心的用户。其核心机制是按固定时间间隔弹出全屏提示信息，强制用户中断当前活动，重新集中注意力。

---

## 技术栈

| 层级 | 技术 |
|------|------|
| 前端框架 | React 18 + TypeScript |
| 构建工具 | Vite 6 |
| 桌面壳 | **Tauri 2**（Rust 后端） |
| 样式 | Tailwind CSS 3.4 |
| 测试 | Vitest |
| 图标 | lucide-react |
| 包管理 | npm |

---

## 核心工作流程

1. 应用启动，从操作系统本地 `config.json` 加载配置
2. 默认配置：每 **3 秒** 弹出一条中文提示语——"回到当前最重要的事"
3. 两次提醒之间，窗口处于隐藏状态，不打扰用户
4. 定时器触发 → 窗口变为 **全屏、置顶、聚焦**，显示提示语
5. 用户按 **空格键** 关闭当前提醒
6. 计数器归零，循环重复

## 关键模块解析

### 前端核心：`useReminderApp.ts`

应用的核心逻辑 Hook，负责：
- 挂载时通过 Tauri IPC 加载配置（浏览器模式降级为默认值）
- 基于 `config.intervalSeconds` 启动 `setInterval` 定时器
- 定时器触发时调用 Tauri Window API：`show()`、`setAlwaysOnTop(true)`、`setFullscreen(true)`、`setFocus()`
- 监听 `keydown.Space` 事件，隐藏窗口并重置状态
- 暴露 `reloadConfig` 方法支持配置热重载

### 后端核心：`lib.rs`

- 定义 `ReminderConfig` 结构体（message + interval_seconds）
- 在 `%APPDATA%/adhd_helper/config.json` 路径管理配置文件
- 若文件缺失，自动创建并写入默认值
- 通过 Tauri 命令 `load_config` 向前端暴露数据

### 数据模型

```typescript
interface ReminderConfig {
  message: string         // 提示文案（默认："回到当前最重要的事"）
  intervalSeconds: number // 提醒间隔秒数（默认：3，最小：1）
}
```

## 构建与运行

| 命令 | 用途 |
|------|------|
| `npm run dev` | 启动 Vite 开发服务器（浏览器模式） |
| `npm run build` | TypeScript 检查 + 前端构建 |
| `npm run tauri` | 执行 Tauri CLI |
| `npm run test` | 运行 vitest 单元测试 |
| `npm run lint` | ESLint 代码检查 |
| `npm run preview` | 预览 Vite 构建产物 |
| `adhd-helper-debug.cmd` | 以调试模式启动桌面应用（带控制台） |

最终发布产物：`npx tauri build` → 原生 Windows exe（`adhd_helper.exe`），不依赖 Node.js/Python 运行时。

## 设计观察

### 优点
- **功能聚焦**：单一职责，代码精简，易于理解和维护
- **架构清晰**：按 services / hooks / components / types / utils 分层组织
- **配置持久化**：通过 Rust 后端管理 OS 原生配置文件路径
- **浏览器降级**：非 Tauri 环境可自动回退，方便开发和调试
- **完整的 Trae.ai 设计文档**：需求、架构、规格、任务拆解一应俱全

### 待优化/未完成项
- `zustand`、`react-router-dom` 在 `package.json` 中但源码未使用
- `useTheme.ts` Hook 和 `Empty.tsx` 组件存在但未被引用
- 无系统托盘（tray）功能，应用只能通过任务管理器退出
- 不支持开机自启
- 当前仅支持单条固定提示语，不支持文案轮换

### 技术债务
- `index.html` 标题仍为 "My Trae Project"，未更新为应用名
- 未使用的依赖会增加构建体积和安全检查开销

## 总结

ADHDHelper 是一个**极简但完整的桌面应用**，利用 Tauri v2 的 Rust 后端 + React 前端的组合，实现了"定时全屏提醒"这一单一功能。代码质量良好，结构清晰，适合作为 Tauri 入门项目或在此基础上扩展更多 ADHD 辅助功能（如提示文案轮换、统计追踪、白噪音等）。
