# 全屏提示词提醒器 Spec

## Why
需要一个极简但可分发的桌面提醒工具：按固定时间间隔弹出全屏提示词，强制打断当前分心状态，并允许用户通过空格键快速取消。
项目应优先满足免环境分发、跨平台和后续扩展性，因此需要先明确交互边界与技术路线。

## What Changes
- 新增一个桌面提醒器应用，支持按固定间隔显示全屏提示词。
- 支持通过配置设置提示词内容与提醒间隔，首版默认间隔为 3 秒。
- 支持在提醒界面按空格键关闭当前提示。
- 提醒界面默认全屏、置顶、聚焦，尽可能占满屏幕并减少误操作成本。
- 支持打包为独立可执行应用，用户无需额外创建运行环境。
- 预留后续扩展点：多提示词轮换、系统托盘、开机启动、不同提醒样式、平台差异化行为。
- 技术路线建议优先采用 `Tauri + Web UI`：体积较小、跨平台能力较好、分发体验优于依赖 Python 运行环境的方案。

## Impact
- Affected specs: 桌面提醒、配置管理、全局键盘交互、应用打包分发
- Affected code: 桌面应用入口、提醒调度器、全屏覆盖层 UI、配置读写模块、打包脚本

## ADDED Requirements
### Requirement: 周期性全屏提醒
系统 SHALL 允许用户按设定时间间隔触发全屏提醒，并展示一条提示词。

#### Scenario: 到达提醒时间
- **WHEN** 应用正在后台运行且达到设定的提醒间隔
- **THEN** 系统显示一个占满屏幕的提醒界面
- **AND** 提醒界面展示当前提示词
- **AND** 提醒界面保持置顶并获取焦点

### Requirement: 空格键关闭当前提醒
系统 SHALL 允许用户通过空格键关闭当前一次提醒，而不退出整个应用。

#### Scenario: 用户取消当前提醒
- **WHEN** 提醒界面处于显示状态且用户按下空格键
- **THEN** 当前提醒界面立即关闭
- **AND** 应用继续保留下一次周期性提醒能力

### Requirement: 可配置提示词与时间间隔
系统 SHALL 提供简单配置能力，至少支持设置单条提示词与提醒间隔秒数。

#### Scenario: 启动时读取配置
- **WHEN** 应用启动
- **THEN** 系统从本地配置读取提示词与时间间隔
- **AND** 在配置缺失时使用默认值

### Requirement: 可分发的桌面应用
系统 SHALL 可被打包为无需用户手动安装额外运行环境的桌面应用。

#### Scenario: 最终分发
- **WHEN** 开发者执行打包流程
- **THEN** 产物可直接分发给目标平台用户使用
- **AND** 用户不需要单独安装 Python 或 Node 运行环境

### Requirement: 可扩展架构
系统 SHALL 将提醒调度、配置管理与界面展示解耦，以支持后续扩展。

#### Scenario: 后续新增能力
- **WHEN** 需要加入提示词列表、托盘菜单或开机启动
- **THEN** 现有提醒逻辑无需大规模重写
